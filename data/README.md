# Dados de demonstração

demo_reviews.csv contém dez casos sintéticos, criados para demonstrar classificações e situações de borda do agente. Os identificadores usam o prefixo DEMO-. Nenhum registro é apresentado como avaliação real da Olist.

Para análise real, obtenha o dataset público na página oficial do Kaggle e carregue os CSVs pela interface. Não redistribua os dados originais sem observar a licença e os termos de uso aplicáveis.
